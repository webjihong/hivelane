말로 맡기기

총괄이 팀 구성(역할·모델·예산)을 제안하고, 승인하면 바로 일을 시작합니다.

팀은 동시에

업무마다 브랜치·작업 폴더를 따로 만들고 기획 → 구현 → 검사 → 보고를 실시간으로 보여 줍니다.

나는 결정만

질문은 「지금 볼 것」에 모여 단추로 답합니다. 운영 DB·배포 명령은 꼭 사람 승인을 거칩니다.

맥이 버거워하지 않게

총괄 엔진이 CPU·메모리를 보고 팀을 멈추고 다시 돌리며, 무거운 빌드는 대기열로 돌립니다.

역할마다 계정·모델

Claude·Codex 계정을 역할마다 섞어 쓰고, 한도가 차면 다음 계정으로 바꿔 하던 대화를 이어 갑니다.

메신저형 화면과 푸시 알림. 내 Tailscale 네트워크 안에서만 열립니다.

설치

Homebrew (권장)

brew tap webjihong/hivelane https://github.com/webjihong/hivelane
brew trust webjihong/hivelane     # Homebrew 7+: allow this tap
brew install --cask hivelane

# 나중에 업데이트
brew upgrade --cask hivelane

업데이트하면 일하는 팀이 없을 때 서버가 새 버전으로 저절로 다시 시작합니다.

DMG

최신 DMG를 받아 Hivelane을 응용 프로그램 폴더로 옮기고, 열어서 「서버 설치하고 시작」을 누릅니다.
